# Agenda Presidencia 5.0 — Preview funcional

Proyecto independiente de la versión 4.5. No reemplaza ni modifica la aplicación estable.

## Qué contiene

- `index.html`: estructura de la aplicación.
- `styles.css`: sistema visual móvil/escritorio y temas claro/oscuro.
- `app.js`: lectura de Google Sheets, edición, creación, estados y eliminación.

## Funcionalidad conservada

La versión 5.0 utiliza las mismas URL operativas de CSV y Google Apps Script que la versión 4.5. Por eso conserva creación, edición, cambio de estado y eliminación.

## Novedades del primer entregable

- Calendario con líneas segmentadas en vez de puntos.
- Línea verde: confirmada; violeta: por confirmar; ámbar: pendiente; gris azulado: ausencia; roja: cancelada.
- Panel del día debajo del calendario en móvil, sin taparlo.
- Deslizamiento horizontal sobre el panel para cambiar de día.
- Vista de dos paneles en computador.
- Resumen ejecutivo dinámico de la jornada.
- Diseño claro y oscuro renovado.

## Prueba segura

Sube esta carpeta a un repositorio nuevo de GitHub Pages. No reemplaces el repositorio de la versión 4.5 durante la evaluación.
